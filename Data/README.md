# Anthropometric Analysis and Foot Length Prediction

## 📌 Project Overview

This project investigates relationships between general anthropometric characteristics and foot measurements using statistical analysis and machine learning.

The analysis combines conventional statistical methods with predictive modeling to:

- Describe anthropometric characteristics
- Compare measurements between male and female participants
- Identify relationships between anthropometric variables
- Investigate factors associated with foot length
- Develop and evaluate machine-learning models for foot length prediction

> **Note:** The dataset used in this project is synthetic. Therefore, the findings are intended for methodological and educational purposes and should not be interpreted as population-level evidence from real participants.

---

## 📊 Dataset

The dataset contains:

- **800 participants**
- **23 variables**
- **405 females**
- **395 males**

### Main Variables

#### Demographic / General Anthropometric Variables

- Age
- Sex
- Height
- Weight
- BMI
- Residence
- Ethnicity/Ancestry Group
- Foot Dominance
- Foot Pathology

#### Foot and Lower-Limb Measurements

- Foot Length
- Foot Breadth
- Instep Length
- Heel Breadth
- Bimalleolar Breadth
- Ankle Height
- Calf Height
- Medial-Lateral Malleolus Height
- Calf Circumference
- Ankle Circumference
- Heel-Ankle Circumference
- Instep Circumference
- Ball of Foot Circumference
